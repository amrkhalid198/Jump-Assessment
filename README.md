# Jump-Assessment Tool
RSI (Reactive Strength Index) assessment prototype, built on a shared design system.

## Structure
- `index.html` — the assessment tool
- `design-system/` — tokens, styles, and the component bundle
- `design-system/tokens/` — colors, typography, spacing, motion, shape, elevation

## Run locally
Open `index.html` in a browser, or serve the folder:

    python -m http.server 8000
